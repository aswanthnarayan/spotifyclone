# 🎵 Spotify Clone

A responsive front-end clone of the Spotify landing page built using **HTML** and **CSS**.

## 🌐 Live Demo

👉 [View Live Site](https://spotify-clone-asw.netlify.app/)

## ✨ Features

- Spotify-inspired modern landing page
- Fully responsive layout
- Custom navigation bar, hero section, and footer
- Styled with pure CSS (no frameworks or JavaScript)

## 🛠 Tech Stack

- HTML5
- CSS3
